## Where to dig

- A precision question: the function's doc comment, then `testdata/stress/` and the `*_precision_test.go` files in the
  package, then `PRECISION_FINDINGS.md`.
- A nondeterminism question: `testdata/determinism/map_ranges.json` names every map loop by `<package>.<function>#k`.
- A golden-file failure: the package's own `testdata/` directory, or the root `testdata/<package>/` directory (both are
  used; see `docs/DATA_MODEL.md`).
- Anything reachable over HTTP: `cmd/reality-compute/server.go` only.
